# Wardogs Mortar Calculator

A static Wardogs mortar/artillery distance calculator.

## Features
- Paste Wardogs coordinates such as `x91, y100`
- Only the numeric X/Y values are used
- Automatic distance calculation
- Distance is calculated as `sqrt((X2-X1)^2 + (Y2-Y1)^2) * 100`
- Optional calculation details
- Save calculations with a custom name
- Optional cardinal direction/bearing such as `250 W`
- Load or delete saved calculations
- Saved calculations persist in the browser with localStorage
- Responsive desktop/mobile layout
- Wardogs background artwork

## Files
- `index.html` — complete website
- `wardogs-background.jpg` — supplied Wardogs background image

## Hosting
This is a static website. Upload both files to a static host such as GitHub Pages, Cloudflare Pages, Netlify, or your own web server.

Clipboard access works best when the site is served over HTTPS.
